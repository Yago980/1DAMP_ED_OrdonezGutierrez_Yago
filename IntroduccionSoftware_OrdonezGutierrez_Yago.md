# Ejercicio 1: Introducción al software



### ¿Qué es un programa informático?

Un programa informático también referido como software es una serie de instrucciones escritas en un lenguaje informático que el ordenador interpreta para ejecutarlo y hacer unas tareas ya especificadas.
